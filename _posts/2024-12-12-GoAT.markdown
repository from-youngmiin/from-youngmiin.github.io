##### 소개 : 빠른 매칭 기반 안전한 택시 합승 시스템 기반 어플리케이션을 제작
##### 개발기간 : 2024.03 ~ 2024.11
##### 맡은 임무 : Full-stack, 기여도 70% 
<pre>
    3인으로 구성 : DBA, FULL-STACK, QA로 나누어 활동
</pre>

##### 사용한 프로그램 : 
<pre>
    Front-End(Flutter), 
    Back-end(Django 3.15.1),
    DB(Mysql 8.0.37, redis 7.2.5),
    Server(Google Cloud Platform(GCP))
</pre>

##### 주요 기능 : 
<pre>
- 안정적인 소속 기관 인증을 받기 위해 해당 소속기관 웹사이트를 로그인 성공 유무 확인
- 출발지의 경도, 위도와 사용자의 GPS 경도 위도를 통한 150m안에 있을 경우 빠른 매칭 알고리즘 작동
- Websocket을 통한 4명 이하의 인원을 매칭되는 알고리즘 
- Redis를 활용한 실시간 채팅
- 카카오페이 API분석 후 결제 알고리즘 적용
</pre>
